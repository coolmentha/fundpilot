# ADR-0018: 定投止盈采用类型推荐与持久化周期

## Context

ADR-0015 将移动止盈从金字塔加仓档位中解耦，但留下了“回撤 n 倍阈值、每天按当前持仓重复卖出”的普通持仓模型。定投会持续改变成本和 lot 持有期；最近一次定投若锁住整仓，会让日定投基金永久无法止盈。

## Decision

- 以 `FundCategory` 提供四类可版本化推荐参数，用户可以覆盖并主动恢复推荐值。
- 只有整仓收益达到启动线才进入止盈周期；周期高点回撤达标后收割部分浮盈。
- 建议卖出份额同时受浮盈收割、单次上限、成熟 lot、最低保留仓位约束。
- `FundStrategyEntity` 持久化 `ACCUMULATING / ARMED / TRIGGERED / COOLDOWN` 周期，保证同一周期只产生一次可执行止盈。
- 止盈确认后进入冷静期；冷静期结束且收益仍达标时直接以当天净值开启新周期，当天不卖。
- 最近买入保护按 FIFO `fund_lot` 逐笔计算，不能锁住旧份额。逻辑止损继续最高优先级并可清仓。

## Considered Options

- 保留单一线性四档：否决，同档会重复卖出，且不看整体盈利。
- 最近买入后冻结整仓：否决，日定投会永久冻结止盈。
- 推荐参数强制随基金类型更新：否决，会覆盖用户决策和已生效版本。
- 为周期单独建表：否决，现有 `fund_strategy` 已承担参数版本和运行时状态，新增一对一表只增加一致性成本。

## Consequences

- 正面：定投新份额与历史底仓分开保护；止盈语义与实际盈利一致；用户有可解释的类型起点。
- 代价：信号生成、两条交易确认路径和撤单路径都必须推进同一状态机；测试必须覆盖重跑和未回应信号。
- 兼容：保留 `stop_loss_pullback_percent` 列和 API 字段名，迁移仅将负数规范为等价正数并增加列。
