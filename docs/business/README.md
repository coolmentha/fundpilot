# FundPilot 业务逻辑文档

本目录描述当前系统的业务流程、状态机、计算口径、失败语义及实现入口，主要服务于开发者和 AI Agent。

## 阅读顺序

1. 先读 [产品文档](../PRODUCT.md)，了解产品定位和能力边界。
2. 再读 [领域上下文](../../CONTEXT.md)，统一术语和跨模块核心契约。
3. 按任务选择本目录中的业务主题。
4. 需要理解决策原因时查看 [ADR](../adr/)。
5. 最终以当前代码和测试的实际行为为准。

## 跨模块边界

- 基金状态来自交易账本，不来自页面操作或信号生成。
- 自动定投是执行授权，卖出信号是操作建议。
- 单位净值负责记账，累计净值负责复权分析。
- 北京时间决定业务日，数据库以 UTC 00:00 `Instant` 保存日期标签。
- Controller 只做路由；业务分支、事务和失败处理以 Service 为准。
