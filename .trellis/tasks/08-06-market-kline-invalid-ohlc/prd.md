# 修复非法行情数据导致K线失真

## Goal

阻止中证指数接口返回的非法 OHLC 行进入 `index_kline`，避免价格轴被零值拉伸，导致 K 线与成交量区域显示异常。

## Requirements

- 在中证指数 K 线解析边界校验 `open`、`high`、`low`、`close` 均为正数；缺失值按非法处理。
- 混合响应中跳过非法行，保留有效行及其成交量；全部行非法时沿用现有异常语义，触发数据源降级，不生成零值 K 线。
- 增加覆盖零 OHLC 行的解析器回归测试，确保有效行和成交量不受影响。
- 不修改前端图表、不新增依赖、不改变 `MarketDataSourceChain` 的降级契约。
- 生产历史数据修复与代码发布分开执行：先只读核对并备份受影响记录，再按验证结果清理/回填；本任务代码验证阶段不得写生产库。

## Acceptance Criteria

- [x] 非正或缺失 OHLC 行不会出现在解析结果中。
- [x] 有效行的 OHLCV、日期和成交量单位换算保持现有行为。
- [x] `CsindexJsParserTest` 通过，且后端相关测试/构建通过。
- [x] 代码 diff 仅涉及解析器及其回归测试（必要的任务/规范文档除外）。
- [ ] 发布方案明确历史 `index_kline` 的备份、验证和回滚门禁；未获生产写入确认前不执行数据修复。
