# 审计设计

## 证据层级

1. GitHub Issue 当前状态、正文、评论和关闭关联。
2. 关联 PR/提交的变更及测试记录。
3. 当前分支的实现、测试与可运行的定向验证。

关闭 Issue 只有在第 2 或第 3 层提供针对问题的证据时才判为已确认修复；否则标记为关闭但证据不足。开放 Issue 即使实现存在，也标记为代码已修复但 Issue 未关闭。

## 边界

- 当前分支和远程默认分支均作为证据来源，结论注明来源。
- 不执行 Issue/PR 写操作，不修改业务实现，不处理生产数据。
- 用户已有 `deploy/monitor/promtail.yml` 修改排除在审计范围外。
