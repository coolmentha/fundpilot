# 东方财富 push2 接口字段验证

> 验证日期：2026-07-04
> 用途：行情工作台后端数据源接入

## 1. 指数实时行情 ✅

**接口**：`GET https://push2.eastmoney.com/api/qt/ulist.np/get`

**参数**：
- `fields=f1,f2,f3,f4,f5,f6,f12,f14`
- `secids=1.000001,1.000300,0.399006`（逗号分隔，secid 格式：`市场.代码`，1=沪，0=深）

**响应结构**：
```json
{
  "rc": 0,
  "data": {
    "total": 3,
    "diff": [
      {"f2": 404364, "f3": 37, "f4": 1474, "f5": 602009738, "f6": 1465563104853.7, "f12": "000001", "f14": "上证指数"}
    ]
  }
}
```

**字段含义**（关键：数值需要除以 100）：
| 字段 | 含义 | 单位/缩放 | 示例值 | 实际值 |
|------|------|----------|--------|--------|
| `f2` | 最新价（点位） | ÷100 | 404364 | 4043.64 |
| `f3` | 涨跌幅 | ÷100（百分点） | 37 | +0.37% |
| `f4` | 涨跌额 | ÷100 | 1474 | +14.74 |
| `f5` | 成交量 | 手（原值） | 602009738 | 6.02亿手 |
| `f6` | 成交额 | 元（原值） | 1465563104853.7 | 1.47万亿 |
| `f12` | 代码 | 字符串 | "000001" | 上证指数 |
| `f14` | 名称 | 字符串 | "上证指数" | |

## 2. 行业板块涨跌 ✅

**接口**：`GET https://push2.eastmoney.com/api/qt/clist/get`

**参数**：
- `pn=1`（页码）、`pz=20`（每页数）、`po=1`（排序方向）、`np=1`
- `fields=f12,f14,f3,f6`
- `fs=m:90+t:2`（m:90=板块，t:2=行业类）

**响应结构**：
```json
{
  "data": {
    "total": 496,
    "diff": [
      {"f3": -22, "f6": 3858445826.0, "f12": "BK0420", "f14": "航空机场"}
    ]
  }
}
```

**字段含义**：
| 字段 | 含义 | 缩放 |
|------|------|------|
| `f3` | 涨跌幅 | ÷100（-22 = -0.22%） |
| `f6` | 成交额 | 元（原值） |
| `f12` | 板块代码 | 字符串 "BK0420" |
| `f14` | 板块名称 | 字符串 |

## 3. 板块主力资金流向 ✅

**接口**：`GET https://push2.eastmoney.com/api/qt/clist/get`（同板块接口，加资金字段）

**参数**：
- `fields=f12,f14,f3,f62,f66,f72,f78,f84`（加 f62 主力、f66 超大单、f72 大单、f78 中单、f84 小单）
- `fs=m:90+t:2`

**响应字段**：
| 字段 | 含义 | 缩放 |
|------|------|------|
| `f62` | 主力净流入 | 元（原值，正=流入） |
| `f66` | 超大单净流入 | 元 |
| `f72` | 大单净流入 | 元 |
| `f78` | 中单净流入 | 元 |
| `f84` | 小单净流入 | 元 |

> 全市场资金流向（汇总）：不单独拉，前端从板块资金求和或单独算。本期用全市场 A 股的资金流向汇总接口（待定，先用板块聚合）。

## 4. 北向资金实时 ✅

**接口**：`GET https://push2.eastmoney.com/api/qt/kamt.rtmin/get`

**参数**：
- `fields1=f1,f2,f3,f4`
- `fields2=f51,f52,f53,f54,f55,f56`

**响应结构**：
```json
{
  "data": {
    "s2n": ["9:30,0.00,5200000.00,0.00,5200000.00,0.00", "9:31,..."]
  }
}
```

**字段顺序**（CSV，每分钟一条）：
- `[0]` 时间 "HH:MM"
- `[1]` 沪股通净流入（元）
- `[2]` 沪股通余额（元）
- `[3]` 深股通净流入（元）
- `[4]` 深股通余额（元）
- `[5]` 北向合计净流入（元）

取最后一条 = 最新北向资金净流入。

## 5. 字段缩放规律总结

**核心规律**：`f2/f3/f4`（价格/涨跌幅/涨跌额）默认 ÷100，`f5/f6/f62/f66...`（成交量额/资金额）原值。

| 类型 | 字段 | 缩放 |
|------|------|------|
| 价格类 | f2, f4 | ÷100 |
| 百分比类 | f3, f69, f75, f81, f87, f184 | ÷100 |
| 金额类 | f5, f6, f62, f66, f72, f78, f84 | 原值（元） |

## 6. 注意事项

1. **必须带 Referer 头**：`Referer: https://quote.eastmoney.com/` 或 `https://finance.eastmoney.com/`，否则可能 403
2. **User-Agent**：模拟浏览器 UA
3. **f12 代码不含市场前缀**：响应里 `f12="000001"` 不含 `1.` 前缀，需用请求时的 secid 映射
4. **板块 total=496**：含子板块，按涨跌幅排序取前 N 即可
5. **北向资金 s2n 是分钟级**：盘前数据为 0，盘后保留最后一笔
