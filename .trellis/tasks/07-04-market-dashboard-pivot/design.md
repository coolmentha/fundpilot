# Design: 行情工作台 UI/UX

## 1. 设计系统（继承现有）

### 色彩（保持现有，已匹配 Fintech/Crypto 最佳实践）

| Token | 值 | 用途 |
|-------|-----|------|
| `--color-primary` | `#F59E0B` (琥珀金) | 主色调、选中态、CTA |
| `--color-accent` | `#8B5CF6` (紫罗兰) | 辅助强调、KPI卡片 |
| `--color-bg` | `#0F172A` (深海军蓝) | 页面背景 |
| `--color-surface` | `#1E293B` | 卡片/面板 |
| `--color-success` | `#22C55E` | 下跌绿（A股惯例） |
| `--color-danger` | `#EF4444` | 上涨红（A股惯例） |
| `--color-info` | `#3B82F6` | 信息蓝 |

### 字体（保持现有）

- 标题/数据：**Fira Code** (monospace) — 数字对齐、技术感
- 正文：**Fira Sans** — 易读、现代

### 涨跌色约定（A股惯例）

- 上涨 → 红色 `#EF4444`
- 下跌 → 绿色 `#22C55E`
- 平盘 → 灰色 `#94A3B8`
- **必须同时使用图标+颜色**，不能仅靠颜色传达信息（WCAG 无障碍要求）

## 3. 组件设计

### 3.1 大盘指数条 (IndexTicker)

**功能**：
- 横向滚动展示用户关注的大盘指数
- 每个指数卡片显示：名称、最新点位、涨跌幅、涨跌额
- 右侧「+ 编辑」按钮，点击弹出指数选择器
- 数据 5-10s 自动刷新

**交互**：
- 点击指数卡片 → 进入该指数详情（K线图）
- 上涨：卡片顶部有红色微光脉冲
- 下跌：卡片顶部有绿色微光脉冲
- 平盘：无脉冲

**视觉**：
```
┌─────────────┐
│ 上证指数     │  ← 12px Fira Sans, muted
│ 3,421.23    │  ← 20px Fira Code, bold
│ +41.56 +1.23%│ ← 14px Fira Code, danger (red)
│ ▔▔▔▔▔▔▔▔▔▔ │  ← 迷你走势sparkline (最近20个点)
└─────────────┘
```

### 3.2 自选基金行情列表 (FundWatchlist)

**表格列**：
| 列 | 宽度 | 格式 | 说明 |
|----|------|------|------|
| 代码 | 90px | Fira Code | 基金6位代码 |
| 名称 | 140px | 默认 | 省略号截断 |
| 最新净值 | 100px | Fira Code, 4位小数 | 盘中=估算值(带「估」标记) |
| 涨跌幅 | 90px | Fira Code, +红/-绿 | 带↑↓箭头图标 |
| 成交额 | 90px | 缩写(亿/万) | ETF显示，主动基金显示「-」 |
| 持仓 | 90px | 缩写(万) | 无持仓为空 |

**排序**：
- 默认按涨跌幅降序（涨幅大的在前）
- 点击列头切换排序：代码、涨跌幅、成交额
- 排序状态用列头箭头指示

**涨跌幅颜色动画**：
- 数值变化时：背景色短暂闪烁（红涨绿跌，150ms 过渡）
- 使用 `prefers-reduced-motion` 时禁用闪烁

**行状态**：
- 持仓基金：行左侧有 amber 色指示条
- 观察基金：无指示条
- Hover：行背景变亮 `rgba(255,255,255,0.03)`

**移动端**（<768px）：
- 表格转为卡片列表
- 每张卡片：名称+代码 | 涨跌幅(大字) | 净值+成交额

### 3.3 行业板块涨跌 (SectorPerformance)

**布局**：紧凑列表，每行显示板块名称 + 涨跌幅条（进度条样式）

```
半导体    ████████████░░░░  +3.21%
新能源    ██████████░░░░░░  +2.15%
```

- 涨跌条：红色=涨，绿色=跌，条宽=涨跌幅绝对值比例
- 最多显示 10 个板块，底部「查看更多→」
- 右侧显示涨跌幅数字

### 3.4 资金流向 (MoneyFlow)

**布局**：4行关键数据，大数字+趋势箭头

```
北向资金    +12.35亿 ↑
主力资金     -5.67亿 ↓
```

- 净流入=红色↑，净流出=绿色↓
- 数字使用缩写（亿/万）

## 4. K线图设计（基金详情页）

### 4.1 图表库选型：Lightweight Charts

| 对比维度 | ECharts | Lightweight Charts |
|---------|---------|-------------------|
| 包体积 | ~1MB | ~200KB |
| K线图开箱 | 需配置 | 原生支持 |
| 金融图表 | 通用 | 专为金融设计 |
| 性能 | Canvas | Canvas (GPU加速) |
| 实时更新 | 需手动 | 原生支持 `setData` |
| 类型支持 | JS | TS 原生 |

**结论**：选择 **Lightweight Charts (TradingView)** — 专为金融K线设计，体积小，原生支持实时更新，TypeScript 友好。

### 4.2 K线图布局

```

│  [日K] [周K] [月K]    [沪深300指数]     │  ← 周期切换 + 图表标题
├─────────────────────────────────────────┤
│                                         │
│  ████████████████████████████████████   │  ← 蜡烛图区域 (70% 高度)
│  ██  ██  ████  ██  ██████  ██  ██     │
│  ██  ██  ████  ██  ██████  ██  ██     │
│                                         │
├─────────────────────────────────────────┤
│  ██ █████ ██ █████ ██ █████ ██ █████  │  ← 成交量柱状图 (30% 高度)
│                                         │
├─────────────────────────────────────────┤
│  时间: 2024-07-04  开: 4.123  高: 4.156│  ← 十字光标信息栏
│  收: 4.145  低: 4.098  量: 1,234万     │
└─────────────────────────────────────────┘
```

**颜色方案**（与涨跌色一致）：
- 阳线（上涨）：实体 `#EF4444`（红色），空心或实心
- 阴线（下跌）：实体 `#22C55E`（绿色）
- 成交量：涨=红 40% 透明度，跌=绿 40% 透明度
- 网格线：`#334155`（现有 border 色）
- 背景：`#1E293B`（现有 surface 色）

**交互**：
- 鼠标悬停：十字光标 + 浮动信息框（OHLCV）
- 滚轮缩放：调整时间范围
- 拖拽平移：左右浏览历史
- 双击重置：恢复默认视图

## 5. 实时数据刷新策略

### 5.1 前端轮询

```
交易时段 (9:30-11:30, 13:00-15:00):
  ├── 指数行情: GET /api/market/indices/realtime → 5s 轮询
  ├── 基金估值: GET /api/market/funds/estimates?codes=xxx → 10s 轮询
  ├── 板块涨跌: GET /api/market/sectors → 30s 轮询
  └── 资金流向: GET /api/market/money-flow → 30s 轮询

非交易时段:
  └── 停止轮询，显示上一交易日收盘数据（带「已收盘」标签）
```

### 5.2 加载状态

| 场景 | 视觉处理 |
|------|---------|
| 首次加载 | Skeleton 骨架屏（指数条=灰色矩形，表格=5行灰色行） |
| 数据刷新中 | 旧数据保持可见，右上角小 spinner（不遮挡内容） |
| 刷新失败 | 保留旧数据，顶部黄色 Toast 提示「数据更新失败，点击重试」 |
| 网络断开 | 红色 Toast 提示，保留最后数据 |

### 5.3 数据陈旧标识

- 数据超过 2 分钟未更新：指数条右侧显示黄色小圆点
- 数据超过 5 分钟未更新：圆点变红，提示「数据延迟」

## 7. 无障碍与可用性

| 规则 | 实现 |
|------|------|
| 涨跌不只用颜色 | 红色↑箭头 / 绿色↓箭头 + 数字，三者同时出现 |
| 数字格式化 | 大数缩写：1.2万、23.5亿；净值保留4位小数 |
| 触摸目标 | 所有可点击元素 ≥ 44×44px |
| 键盘导航 | 表格行支持 Tab 导航，Enter 进入详情 |
| prefers-reduced-motion | 禁用涨跌闪烁、脉冲动画，数据直接切换 |
| 色彩对比度 | 文字 ≥ 4.5:1 (#F8FAFC on #1E293B = 12.6:1 ✓) |
| 骨架屏 | 首次加载用 Skeleton，非空白屏 |
