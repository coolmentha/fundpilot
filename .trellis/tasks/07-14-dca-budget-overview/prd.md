# 定投预算总览与仓位提醒

## Goal

以可选月度定投预算提供现金流可见性，并以每只基金独立的仓位提醒提示集中度；两者均为提示，不得阻断定投、手动买入、基金转换或净值确认。

## Confirmed Facts

- 现有 `totalCapital`、外部入金与 `maxPositionRatio` 是 V20 引入的硬性买入校验，已导致基金转换转入腿在净值确认时失败。
- 自动定投在实际执行日生成 `INVEST` PENDING 交易；月计划可以在连续休市后跨月顺延，且已取消的计划交易不会重新生成。
- 当前产品没有全局定投页面；定投计划位于基金详情，用户配置位于设置页，基金列表是全局基金视图。

## Requirements

### R1 月度定投预算

- 用户可在“用户配置”设置或清空一个可选的每月定投预算，直接覆盖旧值，不再有外部入金和累计资金池语义。
- 未设置预算时，系统仍计算并展示本月已定投和未来计划，但不展示预算进度、超额状态或红色提示。
- 设置预算后，预算总览显示：本月已定投、本月未来定投、本月预计定投、预算剩余或预计超出金额，以及进度条。
- 本月已定投统计北京时间自然月内所有未取消的 `INVEST` 交易，包含自动与手动定投、`PENDING` 与 `CONFIRMED`。
- 本月未来定投只统计当前有效且启用的自动计划在本月剩余实际执行日会产生的金额；已存在任意状态交易的日期不得再次计入。跨月顺延按实际执行日期归属预算月份。
- 预算超额仅以红色的进度/文字提示呈现，不暂停或修改任何计划，不阻断任何交易流程。

### R2 单基金仓位提醒

- 每只基金具有独立的仓位提醒开关和提醒线；默认开启，默认线为 30%，允许范围为 1% 至 100%。
- 仓位占比仅按当前已确认事实持仓市值计算：该基金持仓市值除以全部基金持仓市值。不实现“定投后预计占比”。
- 当提醒启用且当前占比超过提醒线时，在基金列表中以文字和颜色明确提示；关闭后仍展示占比，但不标红、不弹提示。
- 仓位提醒是纯展示规则，不得在任何买入、定投、转换、建仓或净值确认路径上产生校验异常。

### R3 页面位置与交互

- “用户配置”页用“每月定投预算”替换“总资金池/外部入金”。
- “我的基金”页顶部展示全局“本月定投”总览；不新增导航页面。
- 基金列表将原“仓位上限”列调整为仓位提醒信息；基金编辑表单可配置提醒开关和提醒线。
- 预算进度条必须同时呈现实色的已定投与视觉可区分的未来计划段；数字和超额文字不能仅依赖颜色表达状态。

## Out of Scope

- 不预测市场涨跌或月底仓位。
- 不实现定投累计投入上限、部分执行、自动暂停、预算通知推送或交易所现金余额同步。
- 不新增独立的全局定投导航页。

## Acceptance Criteria

- [ ] 无月度预算时，所有买入、转换和定投可以正常生成及确认，设置页不再显示外部入金。
- [ ] 有预算时，预算总览准确分开展示已定投、未来计划和预计总额；取消交易不计入已定投，跨月顺延按实际执行月统计。
- [ ] 预计金额超过预算时只显示超额提示，相关交易仍能确认。
- [ ] 各基金可独立开关仓位提醒并设置 1% 至 100% 的提醒线；关闭的基金不出现告警。
- [ ] 超过提醒线只影响显示，不影响 `INCREASE`、`TRANSFER_IN`、`INVEST`、初始持仓和相关确认流程。
- [ ] 后端和前端测试覆盖统计、日期边界、预算可选性和无硬拦截回归。
