# 基金详情当日分时图

## Goal

基金详情行情区域提供当日分时曲线，帮助用户查看盘中估值变化；保留既有 K 线 / 净值走势图，二者通过 Tab 切换。

## Requirements

- 行情区域展示“今日分时”和“K线 / 走势图”两个 Tab，默认打开“今日分时”。
- 今日分时只使用后端从同花顺分钟估值接口取得并缓存的数据；浏览器不得直接请求外部数据源。
- 分时点必须属于北京时间当日，且至少有两个有效点才能展示曲线。
- 同花顺请求、解析或日期校验失败时，分时 Tab 显示空态，不得用东方财富单点估值伪造曲线。
- 现有“今日涨跌”估值与确认净值的降级语义保持不变。
- 删除现有“今日行情指标”面板。
- 不新增依赖。

## Acceptance Criteria

- [x] 同花顺有效分钟数据在基金详情页显示为当日分时图。
- [x] 分时图与 K 线 / 净值走势图可独立切换。
- [x] 失败、过期或不足两点的数据只显示空态。
- [x] API 读取缓存，不在用户请求链路调用同花顺。
- [x] 既有当日涨跌逻辑不因分时接口失败而改变。
- [x] 解析、缓存/API 和前端 Tab/空态有自动化测试覆盖。

## Business Documentation Impact

required: 更新 `docs/business/market-and-pnl.md` 与 `CONTEXT.md` 的行情数据缓存契约。
