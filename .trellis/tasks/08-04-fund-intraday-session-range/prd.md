# 修复基金详情分时完整交易时段

## Goal

修复基金详情“今日分时”的时间轴，使其覆盖数据源声明的开盘到休盘范围；未到达的分钟保留时间轴但不绘制价格，确保图表涨幅基准与后端估值口径一致。

## Requirements

- 后端保留同花顺分钟响应中的交易时段信息，并通过当日分时接口传给前端；不得在前端硬编码单一市场时段。
- 前端按交易时段生成完整的可显示分钟轴：午休区间可以省略，已经到达的分钟只展示真实分钟点。
- 当前时刻尚未到达的分钟延伸到当日休盘时间，保留时间刻度但保持价格为空；不得用上一点、基准净值或估算值伪造未来曲线。
- 百分比视图仍以 `baseNav` 为 0% 基准，净值视图仍展示真实净值；两种视图使用相同的开盘到休盘时间范围。
- 不改变今日涨跌、今日盈亏和东方财富单点估值的业务计算与降级语义；同花顺分钟线不可用时仍按现有空态规则处理。

## Acceptance Criteria

- [ ] 使用包含 `0930-1130,1300-1500` 的同花顺夹具时，接口和前端均能识别开盘/休盘边界。
- [ ] 盘中仅有 `09:30` 到当前点时，图表时间轴仍延伸到 `15:00`，未来区间没有价格线、面积或涨幅值。
- [ ] 午休区间不要求占用图表宽度，`11:30` 后可直接衔接 `13:00`。
- [ ] 百分比视图首个有效基准为 `baseNav`，末个已到达点的涨幅等于 `(lastNav / baseNav - 1) * 100`；净值视图的点值不被改写。
- [ ] 后端解析、Redis 快照投影、接口投影和前端组件均有回归测试；现有 lint、前端测试、构建及后端相关测试通过。

## Notes

- 根因证据：同花顺原始响应已有完整时段元数据，当前解析器只保留日期；klinecharts 按数据索引布局，当前组件只提交已有分钟点。
- 受影响范围：`ThsJsParser`/`FundIntradayChart` 及其缓存、查询、HTTP 投影和测试。
- `trellis-brainstorm` 技能在当前项目技能目录中不存在，本规划基于已确认需求、领域文档和代码/上游响应实测继续推进。
