# 图表统一切换为 ECharts

## 目标

将基金详情页的今日分时图和 K 线/走势图统一改用 ECharts，保留现有后端接口、页面入口和用户可见功能，同时修正分时涨跌幅轴的动态对称展示：0% 固定在中线，正负边界绝对值相等。

## 需求

- 删除 `klinecharts`，新增 `echarts`，前端不再依赖两套图表引擎。
- 今日分时继续使用 `useFundIntraday` 和现有交易时段：
  - 按后端 `tradingSessions` 展开分钟类目；午休不产生类目。
  - 已有分钟使用真实净值，未来分钟保留类目但值为 `null`，不得绘制预测线。
  - “涨跌幅”按 `baseNav` 计算百分比；Y 轴上下界动态对称，0% 固定居中。
  - “净值”保留真实净值展示和 Tooltip。
- K 线继续使用 `useFundKline` 和 `chartType`：
  - `kline` 保留蜡烛图、日/周/月切换、MA2/5/10/20/30/60/120/250 勾选，默认 MA5/10/20/30。
  - 保留成交量、MACD、副图“无”切换，以及 OHLCV、MA、DIF、DEA Tooltip。
  - `nav` 保留累计净值面积图，不显示 K 线工具栏和指标。
  - 保留暗色/亮色主题适配、十字线、移动端缩放/拖拽、加载/错误/空数据状态。
- 不修改后端请求路径、响应字段、数据源和轮询策略。
- 图表实例必须在组件卸载或图表类型变化时销毁，并在窗口/容器尺寸变化时重绘。

## 验收标准

- [ ] `frontend/src` 中不再存在 `klinecharts` 的导入或调用，依赖清单和锁文件仅保留 ECharts。
- [ ] 分时百分比模式的 Y 轴 `min + max = 0`，即使所有实际点同向或只有正值，也能看到中线 0%。
- [ ] 分时交易段、午休、未来空槽行为与现有后端契约一致。
- [ ] K 线全部现有工具栏选项和指标切换可用，NAV 降级模式可用。
- [ ] 组件测试覆盖分时对称轴、未来 `null`、午休跳过、K 线指标和图表生命周期。
- [ ] `npm run lint`、`npm test`、`npm run build` 全部通过。
- [ ] 本地开发服务下至少检查桌面和 320px 移动宽度，确认图表非空、无重叠、Tooltip/缩放可用。

## 约束与非目标

- 本任务不改后端 API、数据库、行情源或页面路由。
- 不引入 ECharts React 包装层；直接使用项目已有 React 生命周期管理 ECharts 实例。
- 不顺带重构其它 SVG 或趋势图组件。
