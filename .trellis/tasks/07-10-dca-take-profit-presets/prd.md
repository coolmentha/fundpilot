# 定投止盈类型推荐

## Goal

将现有仅按净值高点回撤的卖出参数升级为面向定投的止盈策略：系统根据基金类型给出推荐参数，用户可以修改并恢复推荐值；策略以整仓盈利为启动前提，收割部分浮盈并保留长期底仓。

## Background

- 推荐依据使用 `FundCategory`：`BROAD_BASE`、`SECTOR`、`ACTIVE`、`MIXED`；`FundSubType` 只负责数据源与逻辑止损路径，不参与推荐。
- 当前 `FundStrategyEntity` 只有 `stopLossPullbackPercent`，当前算法不判断整仓盈利、没有止盈周期状态，并按当前持仓重复计算档位卖出。
- 定投会持续产生 `INVEST` 交易。最近一次买入不能继续锁住整仓止盈，只能保护对应的新买入份额。
- 推荐值只用于初始化或用户主动恢复，不得因基金类型或推荐版本变化自动覆盖用户参数。

## Requirements

### R1 基金类型推荐

- 系统为四类 `FundCategory` 提供可版本化的推荐参数。
- 初始推荐值：
  - 宽基：启动收益率 15%，高点回撤 6%，浮盈收割 50%，最低保留仓位 50%。
  - 行业：启动收益率 20%，高点回撤 8%，浮盈收割 50%，最低保留仓位 40%。
  - 主动：启动收益率 15%，高点回撤 7%，浮盈收割 50%，最低保留仓位 50%。
  - 混合：启动收益率 12%，高点回撤 5%，浮盈收割 40%，最低保留仓位 60%。
- 通用推荐：单次最多卖出当前持仓 20%，止盈后冷静期 10 个交易日。

### R2 用户覆盖

- 新建策略时按基金当前 `FundCategory` 自动带入推荐值。
- 用户可修改全部推荐参数，修改后标记为自定义。
- 提供“恢复类型推荐值”，由用户主动触发覆盖。
- 已生效策略仍通过新版本替换，不能被推荐表更新静默修改。

### R3 定投止盈语义

- 整体收益率达到启动收益率后，策略进入已启动状态并记录止盈周期高点。
- 从周期高点回撤达到阈值后生成一次止盈卖出建议；同一周期不得重复生成可执行卖出。
- 建议卖出金额受以下值共同限制：可收割浮盈、单次最大卖出比例、满足持有期的可赎回份额、最低保留仓位。
- 止盈执行后进入冷静期；到期后重新评估新的止盈周期。
- 冷静期结束时若整体收益率仍达到启动线，直接开启新周期，并以当天净值建立新的周期高点；当天不得立即触发卖出，后续发生新的达标回撤才可再次止盈。
- 逻辑止损继续保持最高优先级，不受最低保留仓位限制。

### R4 参数与边界

- 百分比统一使用正数比例存储和传输，例如 `0.06` 表示 6%。
- 后端必须校验必填、正数、参数上下界和参数间关系；前端同步提供输入限制与解释。
- 推荐来源、推荐版本和是否自定义必须可查询，供前端解释推荐依据。

### R5 兼容与展示

- 保留存量策略和历史信号可读性，迁移不得静默改变已生效策略的实际参数。
- 前端显示当前推荐类型、推荐值、自定义状态、恢复入口，以及止盈计算规则摘要。
- 已移除校准流程后，草稿状态不再显示为“待校准”。

## Acceptance Criteria

- [x] AC1 四类基金创建策略时分别得到 R1 中的推荐值。
- [x] AC2 用户修改推荐值后保存为自定义，重新查询保持用户值。
- [x] AC3 只有用户点击恢复推荐值时，参数才恢复为当前基金类型的推荐值。
- [x] AC4 未达到整体盈利启动线时，净值回撤不生成移动止盈信号。
- [x] AC5 同一止盈周期最多生成一次可执行止盈；止盈后进入 10 个交易日冷静期，到期且收益仍达标时从当日新高基准直接开启下一周期。
- [x] AC6 定投新买份额的持有期保护不阻止旧份额参与止盈。
- [x] AC7 建议卖出不超过可收割浮盈、当前持仓 20%、成熟可赎回份额和最低保留仓位四项上限。
- [x] AC8 逻辑止损仍可建议清仓，并保持高于定投止盈的优先级。
- [x] AC9 非法参数由后端拒绝，前端给出可理解的校验提示。
- [x] AC10 存量策略与历史信号可读取，后端测试与前端构建通过。

## Out of Scope

- 自动执行赎回；本期仍生成建议，由用户确认实际卖出份额。
- 基于历史回测自动寻优推荐值。
- 根据市场行情实时改变推荐模板。
