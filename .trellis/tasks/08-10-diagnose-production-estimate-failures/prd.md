# 诊断生产基金估值持续失败

## Goal

基于生产日志和当前估值降级链，定位生产环境持续出现基金估值失败的具体数据源、异常根因和影响范围，并停止 QDII 盘中估值刷新。

## Requirements

- 只读查询生产 Grafana/Loki、公开接口和 GitHub 部署证据，不修改生产数据或配置。
- 区分同花顺、东方财富静态页、ETF IOPV、fundgz 各数据源的失败。
- 统计失败基金、异常类型、时间分布和降级是否最终成功。
- 结论必须引用完整异常 cause，不能仅依据外层日志文案推测。
- QDII 不再进入启动预热、A 股交易时段或扩展时段的盘中估值外部调用。
- 已缓存的 QDII 估值必须清除并标记为 `UNAVAILABLE`，继续使用既有确认净值收益规则。

## Acceptance Criteria

- [x] 取得一组可重复查询的生产错误日志样本。
- [x] 说明主要根因、触发条件和实际业务影响。
- [x] QDII 不再调用盘中估值数据源，晚间和跨夜不再运行 QDII 估值调度。
- [x] QDII 旧估值缓存被失效为 `UNAVAILABLE`，普通基金估值行为不变。

## Notes

- 轻量诊断与单点修复，PRD-only。
