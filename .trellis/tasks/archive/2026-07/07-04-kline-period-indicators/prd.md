# K线周期切换修复+指标(MA/MACD/成交量)

## Goal

行情工作台基金详情页的 K 线图三个问题:
1. 日K/周K/月K 切换后图表完全一样(周期参数被吞)。
2. 缺技术指标(MA、MACD)和成交量可视(降级净值走势时无成交量)。
3. 指数 K 线拉取偶发失败直接降级净值走势,无重试无第二数据源兜底。

参考支付宝基金 K 线:蜡烛图 + 成交量 + MA 均线 + 指标切换(MACD/KDJ 等),暗色紧凑。

## Requirements

- **R1 周期切换真正生效**:日K/周K/月K 切换返回对应周期的 OHLCV,不再都是日K。
- **R2 指标 - MA 均线**:主图叠加 MA5/MA10/MA20/MA30(可开关),A 股惯例配色。
- **R3 指标 - MACD**:副图 MACD(DIF/DEA/MACD 柱),可开关。
- **R4 成交量**:副图成交量柱(红涨绿跌),K 线模式常驻显示。
- **R5 指标可切换**:像支付宝那样用 chip 切换主图指标(MA)和副图指标(MACD/VOL/none)。
- **R6 鲁棒性**:指数 K 线拉取瞬时失败(Unexpected end of file)时重试一次,避免偶发连接中断直接降级净值走势(secid `2.930713` 经验证可用,失败是瞬时网络抖动)。同花顺指数 K 线解析属未来工作(其 API 路径/格式未对接,本期不实现)。
- **R7 净值走势兼容**:主动/混合基金仍展示累计净值折线(无指标无周期切换),行为不变。
- **R8 暗色主题**:对齐支付宝/行情工作台暗色风格,图表紧凑。

## Acceptance Criteria

- [ ] AC1 ETF/指数基金切换日K/周K/月K,蜡烛数量与时间跨度明显不同(周K 蜡烛少于日K,月K 更少)。
- [ ] AC2 MA 开启时主图叠加 MA5/MA10/MA20/MA30 四条均线,图例显示当前各 MA 值。
- [ ] AC3 MACD 开启时副图显示 DIF/DEA 线 + MACD 红绿柱。
- [ ] AC4 成交量副图常驻(K 线模式),红涨绿跌。
- [ ] AC5 chip 可切换主图指标(MA on/off)与副图指标(MACD/VOL/none)。
- [ ] AC6 模拟 eastmoney 瞬时失败时,重试一次后成功(不降级净值走势)。
- [ ] AC7 主动/混合基金仍显示净值折线,无周期切换无指标。
- [ ] AC8 `mvn test` 全绿;前端 `npm run build` 通过。

## Out of Scope

- KDJ/RSI/BOLL 等其他指标(架构支持,首版只做 MA+MACD+VOL)。
- 复权切换(前复权 fqt=1 已固定)。
- 实时分时/K 线(本期只做历史日/周/月 K)。
- 指标参数自定义(MA 周期、MACD 12/26/9 固定)。
