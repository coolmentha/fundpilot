# Implement: 定投预算总览与仓位提醒

## Execution Order

1. 添加数据库迁移和实体/DTO/请求字段，移除总资金池与硬仓位校验。
2. 实现月度定投摘要服务、查询和 API，复用交易日历与 DCA 幂等规则。
3. 更新设置页、基金列表与编辑表单，接入新数据与状态展示。
4. 更新领域文档、ADR/规格，并移除旧错误码和旧产品文案。
5. 补后端单元/集成测试和前端测试，运行质量检查、构建与目标测试。

## Validation

- 后端：聚焦 DCA 摘要、交易确认、转换确认、用户配置和基金服务测试；具备 Java 25 时运行完整 Maven 测试。
- 前端：运行现有 lint、test 与 production build。
- 数据库：校验 Flyway 迁移在空库和带 V20 数据的数据库均能升级。

## Risks and Rollback

- 风险：月计划跨月顺延的预测与 Job 语义不一致。保护：共享日期计算测试并验证已有交易日期排除规则。
- 风险：删除硬校验后遗漏调用点。保护：覆盖 INCREASE、TRANSFER_IN、INVEST 和初始持仓的确认路径。
- 回滚：通过后续迁移恢复旧字段/约束；不删除交易或净值历史。
