# 技术设计：基金详情当日分时图

## 边界与数据流

同花顺 `chart` 响应由既有 `ThsFundEstimateClient` 获取。解析器从同一响应同时产出当前估值快照和分钟点；`MarketRealtimeCache` 在既有估值刷新周期内保存合格分钟点。只读 Controller 从缓存投影为 View DTO，前端 React Query 请求内部 API 并绘图。

## 契约

- 分时点：北京时间 `HH:mm` 和估值净值；响应带基准净值和最后刷新时间。
- 仅当源数据日期为北京时间当日且有效点至少两个时，缓存并返回数据；否则视为无数据。
- 缓存刷新失败只清除对应分时缓存，不影响既有 `FundEstimateSnapshot` 的数据源降级逻辑。
- 前端空态统一表达“暂无当日分时数据”，不回退为单点或历史数据。

## UI

`FundMarketTab` 顶层保留行情内容，在内部使用 Ant Design Tabs：默认“今日分时”，另一项为既有“K线 / 走势图”。分时图复用项目已有图表实现能力，不引入新包。

## 回滚

移除分时 API 与 Tab 后，既有 K 线图和估值接口无需数据迁移即可恢复。
