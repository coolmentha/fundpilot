# 基金分组实施计划

1. 新增 Flyway 迁移、分组实体与仓储，并补充名称唯一性约束。
2. 实现分组批量管理服务、Controller、请求/视图 DTO 与错误码测试。
3. 扩展基金新建/更新和 `FundView` 的多分组契约，补充集成测试。
4. 增加前端分组 hooks、筛选工具及其单元测试。
5. 在基金管理页实现标签筛选、多选创建和管理弹窗拖拽排序。
6. 在首页持仓实现只读标签筛选。
7. 运行后端 `mvnw verify`；前端 `npm run lint`、`npm test`、`npm run build`。
8. 浏览器验证桌面与移动端：筛选、新建多分组、重命名、删除、拖拽保存和取消。

## 影响与回滚点

- 影响数据库 schema、基金 API DTO 和两个前端列表。
- 不改变持仓、收益、交易和信号计算。
- 代码可按迁移、后端、前端三个逻辑批次审查；生产回滚使用现有发布备份机制。
