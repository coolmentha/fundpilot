# 智能定投

## Goal

让用户在保留现有定投周期和自动记账体验的前提下，根据市场状态动态调整每期定投金额，在市场相对低位多投、相对高位少投。

## Background

- 现有定投计划按固定金额执行，并在命中周期时自动生成 `INVEST/PENDING` 内部交易。
- FundPilot 不连接基金销售平台，系统生成交易不代表真实扣款或申购。
- 智能定投改变的是每期金额计算，不改变定投作为自动执行机制的既有语义。

## Requirements

- 用户可为定投计划选择固定金额或智能金额模式。
- 新建计划默认选择固定金额，现有计划迁移后也保持固定金额行为。
- 智能金额以用户配置的基础金额为计算基准。
- 智能金额模式提供与支付宝当前产品语义一致的三种策略：低估、均线、涨跌幅。
- 三种策略采用本地版本化规则快照；规则基线为已核验的 2025-06 支付宝 App 界面，后续变化通过人工评估和版本升级引入。
- 低估策略仅适用于具有跟踪指数和指数 PE 历史数据的基金：指数上一交易日 PE 处于可用历史样本 30% 及以下分位时按基础金额执行，正常或高估时本期不生成交易；上一交易日数据缺失时使用最近一期可用估值。
- 均线策略比较参考指数上一交易日收盘价与长期均线：高于均线时减少投入，低于均线时增加投入，并按近 10 个交易日收盘价振幅修正异常短期波动；实际金额限制在基础金额的 60% 到 210%。
- 均线策略默认使用基金的基准指数，用户可以改选参考指数；均线周期可选 180、250、500 个交易日，默认 250 个交易日。
- 涨跌幅策略比较最新基金净值与当前平均持仓成本：高于成本时少投、低于成本时多投，实际金额限制在基础金额的 50% 到 200%。
- 低估策略缺少上一交易日估值时，使用最近一期可用历史估值，并向用户展示实际估值日期。
- 均线策略缺少足够指数 K 线，或涨跌幅策略缺少最新净值/平均持仓成本时，本期跳过并记录数据不可用原因；不得降级为固定金额。
- 智能计划命中执行周期后，自动计算本期金额并生成 `INVEST/PENDING` 交易。
- 历史交易保留执行时的实际金额，不因后续策略或计划调整而变化。
- 暂停、恢复、停用、删除、交易日顺延和同日幂等规则继续沿用现有定投计划规则。
- 月度预算中的“本月剩余预计”和预算进度继续按基础金额计算，并标注实际金额以执行日策略结果为准。
- 智能计划同时展示本月未来金额区间：低估为基础金额的 0% 到 100%，均线为 60% 到 210%，涨跌幅为 50% 到 200%。
- 用户可以在计划列表看到最近一期智能定投决策，包括执行或跳过结果、实际金额、扣款率、规则版本、数据日期和可读原因。

### 均线扣款率

参考指数高于均线时，按偏离幅度使用以下扣款率：

| 高于均线幅度 | 扣款率 |
| --- | ---: |
| 0% 到 15% | 90% |
| 15% 到 50% | 80% |
| 50% 到 100% | 70% |
| 100% 及以上 | 60% |

参考指数低于均线时，先计算近 10 个交易日收盘价振幅 `最高收盘价 / 最低收盘价 - 1`，再使用以下扣款率：

| 低于均线幅度 | 近 10 日振幅达到 5% | 近 10 日振幅低于 5% |
| --- | ---: | ---: |
| 0% 到 5% | 60% | 160% |
| 5% 到 10% | 70% | 170% |
| 10% 到 20% | 80% | 180% |
| 20% 到 30% | 90% | 190% |
| 30% 到 40% | 100% | 200% |
| 40% 及以上 | 110% | 210% |

### 涨跌幅扣款率

涨跌幅按 `(最新基金单位净值 - 平均持仓成本) / 平均持仓成本` 计算：

| 涨跌幅 | 扣款率 |
| --- | ---: |
| `x >= 25%` | 50% |
| `20% <= x < 25%` | 52.5% |
| `15% <= x < 20%` | 55% |
| `10% <= x < 15%` | 60% |
| `7.5% <= x < 10%` | 70% |
| `5% <= x < 7.5%` | 80% |
| `2.5% <= x < 5%` | 90% |
| `-2.5% <= x < 2.5%` | 100% |
| `-5% <= x < -2.5%` | 120% |
| `-7.5% <= x < -5%` | 140% |
| `-10% <= x < -7.5%` | 160% |
| `-15% <= x < -10%` | 180% |
| `-20% <= x < -15%` | 190% |
| `-25% < x < -20%` | 195% |
| `x <= -25%` | 200% |

## Acceptance Criteria

- [ ] 固定金额计划的执行结果与现有行为一致。
- [ ] 用户可以选择低估、均线或涨跌幅策略，并看到计算依据、基础金额和可能的实际金额范围。
- [ ] 新建计划默认固定金额，旧计划升级后仍按原金额执行。
- [ ] 低估策略在低估区按基础金额执行，在正常或高估区跳过本期且记录可查询的跳过原因。
- [ ] 均线策略按参考指数、长期均线偏离和近 10 日振幅得到 60% 到 210% 的扣款率。
- [ ] 均线策略默认带出基金基准指数和 250 日均线，用户可以修改参考指数并选择 180/250/500 日均线。
- [ ] 涨跌幅策略按最新基金净值相对平均持仓成本的涨跌幅得到 50% 到 200% 的扣款率。
- [ ] 策略输入缺失时按各策略降级规则执行，并可查询本期跳过原因和实际数据日期。
- [ ] 智能金额计划在命中周期时按当日市场状态计算一次本期金额，并自动生成一条 `INVEST/PENDING` 交易。
- [ ] 同一计划同一北京时间自然日重复执行不会生成第二条交易。
- [ ] 生成后的实际金额不受后续计划配置变化影响。
- [ ] 月度预算主金额按基础金额估算，并展示智能计划未来金额区间及“实际以执行日为准”的说明。
- [ ] 系统不会调用外部基金平台或宣称已真实扣款。
- [ ] 智能计划列表可展示最近一期执行或跳过决策及其规则版本、数据日期和原因。

## Out of Scope

- 对接支付宝、基金公司、券商或其他外部交易平台。
- 运行时抓取支付宝 App 配置或依赖支付宝内部接口。
- 自动检测或自动同步支付宝未来的规则变更。
- 自动扣款、自动申购或校验外部订单结果。
- 参数回测和自动参数优化。
- 智能定投完整历史决策明细页；本期只在现有计划列表展示最近一期决策，执行记录仍持久化保留。

## Notes

- 本任务属于复杂跨层功能，需求收敛后需要补充 `design.md` 和 `implement.md`。
- 支付宝规则依据公开页面中的支付宝官方 App 截图核验，截图日期为 2025-06-24 和 2025-06-29；支付宝未公开策略 API。
- 支付宝截图中同时出现 250 日均线推荐、180 日均线选项和 500 日均线示例，二手文章文字又称固定 500 日，证据不完全一致；本地产品按已确认的 180/250/500 日可选、默认 250 日实现。
- 档位区间统一按下界包含、上界不包含处理，最外侧区间包含边界，避免临界值产生重叠。
