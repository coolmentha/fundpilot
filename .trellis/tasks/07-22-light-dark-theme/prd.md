# 添加白天黑夜模式切换

## Goal

为 FundPilot 增加可访问的白天/黑夜主题切换，让用户在不同环境下获得清晰、舒适的金融数据阅读体验，同时保持现有黑夜模式不变。

## Background

- 当前 Ant Design 主题集中定义于 `frontend/src/main.jsx`，固定使用 `theme.darkAlgorithm`。
- 全站自定义颜色主要由 `frontend/src/styles.css` 的 CSS 变量控制。
- 顶栏操作位于 `frontend/src/components/Shell.jsx`，适合放置全局主题切换入口。
- 白天模式采用克制的中性灰白背景、深色正文和蓝色交互色；涨跌红绿语义保持不变。

## Requirements

- 在桌面端和移动端均提供白天/黑夜模式切换入口，使用太阳/月亮图标并提供 Tooltip 与 `aria-label`。
- 复用 Ant Design 的 `defaultAlgorithm` 与 `darkAlgorithm`，不新增主题依赖。
- 使用现有 CSS 变量提供完整白天配色，覆盖页面背景、表面层、边框、文字、侧栏、顶栏及常见半透明背景。
- 用户选择写入 `localStorage`，刷新页面后继续使用；首次访问默认保持现有黑夜模式。
- 主题切换不刷新页面，不改变业务数据、路由或页面布局。
- 白天模式正文与弱化文字满足可读性要求，键盘焦点清晰，切换不产生布局位移。

## Acceptance Criteria

- [ ] 顶栏主题按钮可在白天与黑夜模式间即时切换，图标、提示和无障碍名称与目标操作一致。
- [ ] 刷新后恢复上次选择；无已保存选择或保存值非法时使用黑夜模式。
- [ ] Ant Design 组件与自定义页面样式同步切换，不出现深色卡片残留、不可见边框或低对比文字。
- [ ] 375px、768px、1024px、1440px 视口下按钮和标题不重叠，页面无新增横向滚动。
- [ ] 主题状态逻辑有最小自动化测试，`npm run lint`、`npm test`、`npm run build` 均通过。

## Out of Scope

- 不提供更多自定义主题、配色编辑器或跟随日出日落功能。
- 不重构现有页面、组件层级或业务交互。
- 不新增字体、图标或状态管理依赖。
