# 前端Dashboard与基金详情页持仓跟踪优先重构

## Problem Statement

FundPilot 当前的产品重心偏向"定投 + 移动止盈策略"，但作为个人投资者，核心需求是三个：

1. **统计持仓**：快速录入和管理基金持仓，知道每只基金投了多少、成本多少、赚了还是亏了。
2. **交易中实时看涨跌**：盘中打开就能看到持仓的实时涨跌和盈亏，不用手动刷新。
3. **行情**：看到大盘指数走势，以及每只基金跟踪的指数涨跌。

定投只是辅助功能——大部分基金只是持仓跟踪，偶尔几只才开定投。但当前产品把定投放在了过重的优先级上：

- 建仓表单强制要求填写每期定投金额（默认 1000，必填）
- Dashboard 显眼位置展示"定投合计"卡片，却没有"持仓总市值"
- 基金列表 12 列宽表，定投列占第 6 位，核心的涨跌盈亏排在后面
- 没有自动刷新，交易时段想看涨跌得手动点刷新
- 没有大盘指数行情，也没有基金跟踪指数的涨跌对比
- 没有净值走势图，看行情只能看数字

## Goals

1. 定投降级为可选功能，不再强制填写
2. Dashboard 以持仓盈亏和行情为核心，定投降级
3. 基金详情页信息分层，核心持仓数据一目了然
4. 基金列表页优化为"快速扫一眼涨跌"
5. 手动加仓/减仓作为一级操作
6. 建仓表单以持仓信息为主，定投折叠
7. 大盘指数行情 + 基金跟踪指数行情
8. 净值走势图（现代化图表）
9. 交易时段自动刷新

## Requirements

### 1. 定投金额可选

- 前端 `FundsPage.jsx`：`dcaAmount` 字段去掉 `rules={[{required: true}]}`，`emptyForm.dcaAmount` 从 `1000` 改为 `undefined`
- 后端无需改动（已是 nullable，null 时 DCA 静默跳过）

### 2. 未启用定投显示

- `dcaAmount` 为 null 时，列表页和详情页显示灰色文字"未启用"，不显示 `¥0.00`

### 3. Dashboard 重排

- 核心区：今日盈亏合计、持仓总市值、上涨基金、下跌基金、大盘指数行情
- "总可投资金"卡片替换为"持仓总市值"
- 定投合计降级或去掉

### 4. 基金详情页分层

- 一级：持仓概览卡片（市值、涨跌、盈亏、成本价）+ 基金跟踪指数涨跌
- 二级：净值走势图
- 三级：定投配置（折叠面板）
- 四级：策略参数、交易流水

### 5. 基金列表页优化

- 列重排：名称 → 今日涨跌/盈亏 → 持仓市值 → 总盈亏 → 成本价 → 类型 → 状态
- 定投列移到末尾，null 时显示"未启用"
- 默认按今日涨跌幅降序排序
- 顶部加状态 Tab 筛选：全部 / 持仓中 / 未建仓，默认"持仓中"

### 6. 手动加仓/减仓为一级操作

- 详情页持仓概览卡片旁放"加仓"/"减仓"按钮，弹窗填写

### 7. 建仓表单优化

- 三区结构：基金识别 → 持仓信息（核心） → 定投配置（默认折叠）

### 8. 大盘行情 + 基金跟踪指数行情

- Dashboard 顶部：大盘指数卡片（沪深300、中证500、创业板指等）
- 基金详情页：基金跟踪指数（`benchmarkIndexCode`）实时涨跌
- 数据源：东方财富指数 K 线接口

### 9. 净值走势图

- 现代化图表（如 recharts），默认近 3 个月
- 可选叠加跟踪指数 + 标注买入点
- 时间范围可切换：1 月 / 3 月 / 6 月 / 1 年 / 全部

### 10. 交易时段自动刷新

- 9:30-15:00：自动轮询（默认 30 秒，用户可设）
- 15:00-20:00：拉长到 5 分钟
- 20:00 后 / 非交易日：不轮询
- 顶部脉冲指示灯：绿色=实时刷新中，灰色=已收盘
- 后端做限流保护

- [ ] "总可投资金"卡片已替换为"持仓总市值"
- [ ] 基金详情页顶部有持仓概览卡片（市值、涨跌、盈亏、跟踪指数涨跌）
- [ ] 基金详情页有净值走势图，可切换时间范围
- [ ] 净值走势图可叠加跟踪指数，标注买入点
- [ ] 基金详情页有"加仓"/"减仓"按钮，弹窗可录入交易

- [ ] 基金列表页可按状态 Tab 筛选

## Implementation Decisions

### 后端新增端点

| 端点 | 用途 |
|------|------|
| `GET /api/market/index-quotes` | 大盘指数列表实时涨跌 |
| `GET /api/market/index-quote?code={code}` | 单个指数实时涨跌 |
| `GET /api/funds/{fundId}/nav-chart?range=3m` | 基金净值走势图数据 |
| `GET /api/portfolio/summary`（扩展） | 增加 `totalHoldingAmount` |

### 不涉及

- 移动端适配
- 定投策略引擎改动
- 信号引擎改动
- 回测/寻优功能改动
- 后端 `dcaAmount` schema 改动（已是 nullable）
